# 大恒激光线曝光与 FWHM 小实验

日期：2026-08-11

## 结论

- 当前光机条件下，建议标定曝光使用 **500 us、0 dB、Mono8**。
- 300–600 us 都通过现有激光图质量门限；500 us 在 10 帧复测中兼顾了响应、饱和余量和中心重复性。
- GUI 显示的 `FWHM P50/P95 = 6/11 px` 不是 row/column 方向写反，也不是大恒 ISP 锐化或降噪造成。
- 当前 GUI FWHM 的定义确实有一个理论缺陷：它统计整条扫描线上所有高于半高的像素，而不是只统计主峰附近的连续半高区间。不过在本次 300–600 us 数据中，两种定义的 P50/P95 都是 `6/11 px`，因此这个缺陷不是本次大 FWHM 的主因。
- 正式 Steger 中心附近重新测得的插值 FWHM 在 500 us 为 `8.58/12.03 px`；真实海康样本同口径为 `2.28/3.52 px`。所以大恒图像中的正式 ridge 确实更宽，GUI 数值没有虚增，反而在 P50 上低估了 Steger 实际采用的 ridge 宽度。
- 曝光无法把当前大恒线宽从约 6 px 变回海康的约 2 px。100–1200 us 扫描中，GUI FWHM P50 基本一直为 6 px。应优先检查对焦、镜头覆盖与 MTF、工作距离/放大率、光阑，以及激光片光束腰是否落在标定工作面。

## FWHM 公式核查

当前 `laser_scanline_metrics()` 对每条扫描线执行：

1. 背景 = 扫描线中位数；
2. 峰值 = 扫描线最大值；
3. 半高阈值 = `background + 0.5 * (peak - background)`；
4. FWHM = 整条扫描线上高于半高阈值的像素数量。

vertical 配置使用 `scan_axis=row`，归约方向为 x/u，因此方向语义正确。

第 4 步不是严格的单峰 FWHM：如果同一行存在多个亮斑，会把所有半高像素相加。为审计这一点，离线同时计算了：

- GUI 当前的全扫描线计数；
- 最强峰所在连续半高分量宽度；
- 半高交点线性插值宽度；
- 正式 Steger 中心附近 ±24 px 内的连续、插值宽度。

300–600 us 结果：

- GUI 全局计数 P50/P95：`6/11 px`
- 最强峰连续计数 P50/P95：`6/11 px`
- 最强峰插值 P50/P95（500 us）：`5.56/10.67 px`
- Steger 对齐连续 P50/P95（500 us）：`9/12 px`
- Steger 对齐插值 P50/P95（500 us）：`8.58/12.03 px`

约 12.4% 的 active row 存在多个半高分量，但它们没有改变当前 P50/P95。由此判断：公式可以在后续改得更严格，但不能把当前大恒的宽线归因于这个统计定义。

## 与真实海康样本的同口径对照

现有海康数据：

- 相机：`MV-CS050-60GM`，2448 × 2048，Mono8
- 曝光：500 us，增益 0 dB
- 文件：`projects/default/data/.laser_plane.inprogress/fit/laser 001.tif`
- orientation 缺省，按兼容规则为 horizontal

| 指标 | 海康真实样本 | 大恒 500 us 十帧 |
|---|---:|---:|
| GUI FWHM P50/P95 | 2 / 4 px | 6 / 11 px |
| Steger 对齐插值 FWHM P50/P95 | 2.28 / 3.52 px | 8.58 / 12.03 px |
| Steger response P50/P95 | 15.41 / 22.42 | 5.85 / 10.52 |
| Steger valid fraction | 53.0% | 12.3% |

大恒 ridge 更宽、Hessian 曲率响应更弱，而且有效范围更少。这组证据更符合“光学成像中的激光线更散/离焦”，而不是 GUI FWHM 计算把一条实际 2 px 的线错误显示成 6 px。

| 节点 | 当前值 |

| GammaMode | SRGB（Gamma 未启用） |

| NoiseReductionMode / NoiseReduction | Off / 0 |
| FlatFieldCorrection | Off |
| DigitalShift | 0 |

Gamma、锐化、降噪和平场校正均未参与。本算法使用每条扫描线自己的背景中位数，固定黑电平不会直接放大半高宽。

## 为什么同一激光器仍会得到不同像素宽度

激光器相同只说明发射端相同，不保证传感器上的像素剖面相同。像素宽度同时受以下因素影响：

1. **对焦面**：镜头对棋盘纹理清晰，不一定等于对激光所在 3D 平面最佳聚焦；大恒样本呈现较宽且曲率响应较弱，首先应复核焦点。
2. **镜头覆盖和 MTF**：大恒 ME2P-1230 使用 1.1 英寸、4096 × 3000、3.45 um 像元传感器。镜头必须覆盖 1.1 英寸像圈，并在 3.45 um 采样下保持足够 MTF。若沿用只面向较小靶面的镜头，边缘场曲、像散和整体分辨率都可能恶化。型号规格见大恒官方产品页和数据表。
3. **放大率/视场**：焦距、工作距离和视场改变后，同一物理线宽会对应不同像素数。
4. **光阑**：全开时像差可能增大；过小又会出现衍射。应在实际工作距离上比较几档光圈。
5. **激光片光束腰与入射角**：工作面若偏离最窄光束腰，或安装角导致投影展宽，同一激光器也会形成更宽条纹。
6. **饱和**：高曝光会形成平顶并扩宽；本实验 800 us 起已经明显发生，所以不能靠继续加曝光改善线宽。

## 建议的下一步光学验证

保持 500 us、0 dB，不改 Steger 参数：

1. 在标定工作面放置漫反射平面，微调镜头焦点，以 `Steger 对齐插值 FWHM P50/P95` 最小且 response 最大为准；不要只看 GUI 预览缩放图。
2. 检查当前镜头是否明确支持 1.1 英寸像面和 3.45 um 像元；若不支持，换合适镜头做 A/B 对比。
3. 试验 2–3 档光圈，每档重新微调焦点，保持曝光通过激光功率或曝光小范围补偿，同时避免饱和。
4. 在近、中、远工作距离各测一次线宽，判断激光光束腰是否落在有效标定深度内。
5. 若完成光学调整，再运行同一脚本；目标不是强行复现 2 px，而是让 Steger 对齐宽度、response 和中心重复性在整个标定范围内稳定。

本次只新增离线实验和分析脚本；没有修改 GUI、正式质量门限、采集保存门禁或 Steger 数学。
